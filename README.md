# Harness Engineer Study

> **驾驭工程 (Harness Engineering) 系统教学课程**
>
> Agent ≠ LLM + 工具调用。Agent = Model + Harness。
> 引擎决定上限，底盘决定下限。本课程教你构建让模型能持续、稳定、安全运行的工程系统。

## 核心公式

```
Agent = Model + Harness

Model  (引擎):  决定上限 — 最好能有多好
Harness (底盘): 决定下限 — 能稳定地做到多好

引擎再强，没有底盘和刹车，跑不过 100 公里就会车毁人亡。
```
