## 二、知识依赖图

```
学习顺序建议（箭头表示"应先掌握"）：

LLM 原理 ──→ Agent 基础 ──→ Naive Agent 失效分析
                                    │
                                    ▼
                              八大核心机制
                              │    │    │
                    ┌─────────┘    │    └─────────┐
                    ▼              ▼              ▼
              上下文工程        四相循环        工具编排
              任务拆解          验证循环        进度跟踪
              子代理分治        GAN 三角色
                    │              │              │
                    └──────────────┼──────────────┘
                                   ▼
                             三支柱体系
                            (输入/控制/状态)
                                   │
                                   ▼
                             系统架构设计
                                   │
                                   ▼
                             工程实践与运维
```

**第一阶段**（基础）：LLM 原理 → Agent 基础 → 失效分析
**第二阶段**（核心）：八大机制（建议顺序：四相循环 → 工具编排 → 验证循环 → 上下文工程 → 任务拆解 → 进度跟踪 → 子代理分治 → GAN三角色）
**第三阶段**（整合）：三支柱体系
**第四阶段**（应用）：系统设计 → 工程实践

## 三、关键概念速查

| 概念 | 一句话定义 | 详见 |
|------|----------|------|
| **Agent** | Model + Harness 的完整系统 | [破](../01-破-驾驭工程原理与概念.md) |
| **Harness** | 让模型能持续稳定安全运行的工程系统 | [破](../01-破-驾驭工程原理与概念.md) |
| **Naive Agent** | 只有 while 循环 + 工具调用，没有任何防御性机制的 Agent | [破](../01-破-驾驭工程原理与概念.md) |
| **四相循环** | GATHER→ACT→VERIFY→ITERATE 的结构化迭代 | [机制1](../mechanisms/01-四相循环.md) |
